# Battalion Rules v1.6 → v1.18

This directory contains rules for Battalion, corrected to match simulator v1.18.

## Important Note

The rules were significantly updated between v1.6 documentation and v1.18 simulator implementation:
- **v1.6 docs**: Described v1.5 mechanics (simultaneous building, single deck, no ANTE)
- **v1.18 simulator**: Actual implementation (turn-based, two-deck system, ANTE pot)

The documentation in this repository matches **simulator v1.18** (the actual working implementation).

## Files

- `rules.md`: Complete corrected rulebook matching v1.18
- `cards.md`: All 145 event cards with accurate effects
- `../docs/DISCREPANCIES_FIXED.md`: Analysis of what was wrong in original documentation
